📗 Step 2. Qdrantの設定¶

2026/11/27公開 2026/11/28更新

🟩 docker composeでお手軽に¶

🟨 docker-compose.ymlを作って¶

services:
  qdrant:
    image: qdrant/qdrant:latest     # 運用ではバージョンを固定する（例 v1.x.y）
    container_name: qdrant
    restart: always
    ports:
      - "6333:6333"   # REST / Web UI
      - "6334:6334"   # gRPC
    environment:
      QDRANT__SERVICE__API_KEY: "長いランダム文字列"
      QDRANT__TELEMETRY_DISABLED: "true"
    volumes:
      - /mnt/nvme/qdrant/storage:/qdrant/storage
      - /mnt/nvme/qdrant/snapshots:/qdrant/snapshots
    ulimits:
      nofile: { soft: 65535, hard: 65535 }

🟨 bashを流す¶

sudo mkdir -p /mnt/nvme/qdrant/{storage,snapshots}
docker compose up -d
curl -H "api-key: <KEY>" http://192.168.0.100:6333/collections
# Web UI: http://192.168.0.100:6333/dashboard
