🟦 Durantaプロジェクト¶

Durantaは、OpenAirInterface（OAI）のRANとUEのコードを引き継いで、Linux Foundation Networking（LFN）の傘下で開発を続けるオープンソースプロジェクト。OAIプロジェクトでは、NR-UE、5GRAN、5GCNが揃っていて本格的だった。引き続き、いろいろ試すことができそう。
