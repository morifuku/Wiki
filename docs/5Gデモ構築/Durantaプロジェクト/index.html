🟦 Durantaプロジェクト¶

Durantaは、OpenAirInterface（OAI）のRANとUEのコードを引き継いで、Linux Foundation Networking（LFN）の傘下で開発を続けるオープンソースプロジェクトです。

OAIで研究用として育ったRANスタックを、LFNの体制のもとで「商用一歩手前まで持っていけるリファレンス」に格上げしようとしている、と捉えるのが分かりやすいと思います。コードの中身はOAIからそのまま続いていて、大きく変わったのはガバナンス・ライセンス・ホスティングです。

🟩 1. 概要¶

成り立ち

  • 2025年8月に、OSAとLFNがOAIのコミュニティソフトウェアをもとに、新しい候補プロジェクトDurantaを立ち上げると発表しました。

  • 正式に動き出したのは2026年6月22日、ポルトで開かれたOAIサマーワークショップです。OAIのRelease 2026.w24がシードコードになりました。

  • その後、openairinterface5gの開発拠点はGitLab（Eurecom）からgithub.com/duranta-project/openairinterface5gへ正式に移っています。

何を作るのか

  • 研究・試験・初期導入向けの、オープンソースのRANとUEのリファレンススタックです。

  • サブプロジェクトは2つあります。1つはCU/DUとUEの共同開発（ドキュメント、テスト資産、統合用の成果物を含む）を行うRAN & UE、もう1つはCI/CD、パッケージング、ラボ構成、再現性のあるテストハーネス、運用手順書を扱うOperationsです。

  • Core NetworkとO&Mは今は範囲外で、後から追加する予定になっています。

OAIから何が変わったのか

  • ガバナンス：LF Networkingのもとでの中立的なガバナンスと、ガバニングボードの監督・専任スタッフ・セキュリティのベストプラクティスによる組織的な支援が加わりました。OSA（つまりEurecom）主導の色が薄まり、業界企業が参加しやすい形になっています。

  • ライセンス：OAI Public License v1.1を汎用的な表現に書き直したCSSL v1.0に変わりました。研究・試験目的なら特許ライセンスは無償、商用ならFRANDという、3GPP向けの骨格はそのままです。

  • LFN内の連携：CNFのデプロイと自動化を担うLFNのNephioとの統合がうたわれていて、クラウドネイティブな運用を意識しています。

🟩 2. ロードマップ（2026年6月時点の資料から）¶

  • RAN：2026年第2四半期にGPU LDPCアクセラレータ、NR-DC、64 UE対応、第4四半期にFHI 7.2のCat-B、RAN Paging、L1での下りMU-MIMO

  • UE：ハンドオーバ、Sidelinkの基本手順、2レイヤの上り・下り、ATコマンドインタフェース、キャリアスキャン

  • 全体の流れはRAN/UEの基盤づくり → 運用面の整備 → CoreとO&Mへの展開 → 成熟度と適合性（テストスイート、性能のベースライン、リリース基準）の4段階です。
