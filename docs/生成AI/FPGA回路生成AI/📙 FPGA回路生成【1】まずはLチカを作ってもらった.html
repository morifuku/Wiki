📙 FPGA回路生成【1】まずはLチカを作ってもらった¶

(2026/11/1 更新)

ClaudeにFPGAのLチカ（LEDをチカチカさせるだけの電子工作品）を作ってもらった。長いこと放置していた中華FPGA（Tang Nano 9K）がチカチカ点滅しだした。ハードウェアまでClaudeに作ってもらえるなんて、感動もの。人間の仕事はパーツ調達と半田付けくらいしか残ってないな。

🟩 1. 準備¶

使用したFPGAは、秋月電子で購入した、「Tang Nano 9K」3,790円也（2026年10月現在）。チュートリアルもいろいろある。

🟩 2. 実装¶

🟨 2.1 FPGA開発アプリ設定¶

Windows 11にGOWIN FPGA Designer（以下Designer）というFPGA開発アプリをインストールした。教育版という無償バージョンをいれた。このDesignerでFPGA回路を設計したり、FPGAデバイスにそれを焼き込んだりする。インストールしたらUSB-CでWindowsとFPGAデバイスを接続しておく。

🟨 2.2 VisualStudio Codeの設定¶

Visual Studio Code（以下VS Code）に設定したClaudeに渡すCLAUDE.mdファイルに、Designerのインストール場所や、プロジェクトのファイルを置く場所等を記述する。Claudeがそれを認識すると、早速、

🟨 2.3 Lチカつくりますか？¶

とClaudeから聞いてきた。こちらは「はい。お願いします」と言うだけ。すると、自動でビットストリーム（FPGAの回路パターン情報）を作成しFPGAデバイスに流してくれる。そのまま起動してチカチカがはじまる。実にあっけなかった。

🟩 3. まとめ¶

Lチカがあっさりできてしまうと、いろいろと妄想してしまう。。。「ジャイロセンサーからの姿勢情報を読みこんで、その情報でモーターの回転速度を制御する」とか指示するだけでハードウェアができあがってくる。細かい式やパラメータはClaudeとディスカッションしながら仕上げていく。ラズパイとかでは実現できないあれこれが、ハード開発経験のない者に作れるようになったと思うと、わくわくしてくる。

🟩 4. 追加¶

そういえば、Designerはインストールしただけで、全く操作してない。全部VS CodeのClaudeが裏で操作してくれたんだな。すごいな、Claude。人間がDesignerで手を加えると、Claudeはそれを汲み取ってくれるんだな、きっと。
