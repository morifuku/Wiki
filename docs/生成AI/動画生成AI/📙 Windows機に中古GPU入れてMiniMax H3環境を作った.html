📙 Windows機に中古GPU入れてMiniMax H3環境を作った¶

(2026/11/1 更新)

この記事を参考に、MiniMax H3を古いWindows機に導入した。MiniMax H3の仕組みとか、使い方とかに関してはこの記事で勉強させてもらった。残念ながらローカル環境へのセットアップは、どうにもこうにも上手くいかないので、Claude Codeに丸投げした。

🟩 1. セットアップ¶

🟨 1.1 ハードウェアのセットアップ¶

まず、Windows機は以下のかんじでチューンアップした。性能面に関しては、他の環境を試したことないので何とも言えないが、４万円中古RTX3060/12GBでもちゃんと動画を生成してくれる。

チューンアップ前

  • CPU: Intel i7-8700、メモリ: 64GB、GPU:なし

  • ストレージ: 1TB SATA-SSDと1TB NVMe-SSD

  • ケース: スリムケース(ロープロファイル)、電源:300W

チューンアップ後

  • ケースをミドルタワー(標準プロファイル)に大型化、電源を750Wと交換

  • 中古GPU (RTX3060/12GB) 追加

  • 他はそのまま

🟨 1.2 ソフトウェアのセットアップ¶

ローカル環境へのComfy DesktopやMiniMax H3のセットアップが、なかなかうまくいかなかったので、Claude Codeに丸投げした。Comfy DesktopやMiniMax H3を導入する前に、Ollamaを入れてLocal LLMで遊んでいたので、いろいろコンフリクトが起きたのかもしれない。Claude Codeに丸投げすると、バンバン直してくれる。ただ、何がどう直されたのかあまり把握できてない。

  • Python環境の更新

  • Hugging FaceのAPI設定

  • Comfyのストレージ領域の拡張（パンクしそうになって、Claudeに拡張しろと言われた）

  • Comfy Desktopにパッチ当ててた。たぶん何かのバージョンチェック

  • その他

🟩 2. 生成してみた¶

🟩 3. まとめ¶

  • ４万円中古RTX3060/12GBでも、MiniMax H3はちゃんと動画を生成してくれる。

  • セットアップにつまずいても、Claude Codeに丸投げすると、動くまで面倒みてくれる。Comfyの吐き出すエラーメッセージやログメッセージをClaude Codeに渡すだけで、自動で直してくれる。

  • Comfyはバージョンや設定パラメータ値に厳しい頑固者というかんじがした。長い付き合いになると思うので、注意しよう。
