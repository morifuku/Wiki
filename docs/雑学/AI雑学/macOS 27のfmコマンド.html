  • 質問者: Shigeru Morifuku

  • 回答者: Claude Opus 5.5

  • 回答日: 2026/9/30

  • 免責: 回答者は AI であり、間違えることがあります。

🟩 Q: macOS 27のfmコマンドについて概要を説明して#

macOS 27で追加されたfmは、Appleの基盤モデル（Foundation Models）をターミナルから直接使うためのコマンドラインツールです。WWDC26で発表されました。

位置づけ

Appleは新しいコマンドラインツールfmと、Python向けのFoundation Models SDKを発表しており、fmはmacOS 27にプリインストールされています。名前の由来は「Foundation Models」で、任意のターミナルアプリからAppleのオンデバイス言語モデルを実行できます。アカウントやAPIキーは不要で、トークン課金もありません。Apple Silicon搭載Macでのみ動作し、which fmで/usr/bin/fmが表示されればインストール済みです。

主なサブコマンド

fm chatは対話モードです。利用可能なコマンドの確認、fm chatでの対話、オンデバイスモデルとPrivate Cloud Compute（PCC）モデルの切り替え、セッションを保存して後で再開する機能があります。

fm respondはスクリプト向けです。スクリプトなどでインラインに応答を得たい場合はfm respondを使います。またfm schema objectでスキーマを作成し、fm respondの--schemaオプションに渡すことで構造化された出力を得られます。標準入力にも対応しています。

echo 'Explain what the chmod command does, in three sentences.' | fm respond --no-stream > answer.txt

fm availableはモデルの準備状態を確認するコマンドです。

初回セットアップ

使用前にsudo fm licenseでAppleの利用規約に同意する必要があり、管理者パスワードが求められます。オンデバイスモデルはmacOSアップデート後に別途ダウンロードされます。モデルに必要なストレージは7GBで、バックグラウンドでダウンロードされます。modelNotReadyと表示された場合は、Macを電源とWi-Fiに接続したまましばらく待ってから再確認します。

限界と使いどころ

オンデバイスモデルはClaude、ChatGPT、Geminiのようなフロンティアモデルではなく、Apple自身のドキュメントでもコード生成、数学、論理推論には使わないよう推奨されています。macOS 27上で最新のmacOSバージョンを尋ねたところ、実行ごとに「Sonoma」「Monterey」と違う誤答を返したという報告もあります。また使えるのはAppleのオンデバイスモデルとPCCモデルのみです。任意のモデルを試したい場合はOllamaなどの方が適しています。

このため、ファイル分類や要約といった軽い自動化をシェルスクリプトに組み込む用途や、Foundation Models frameworkを使ったアプリ開発前の試用に向いたツールだと言えます。なお、ネイティブアプリから使う場合の本命はSwiftのFoundation Models frameworkで、C/C++から直接呼ぶAPIは用意されていない点には注意が必要です（C/C++から使うならpopenでfm respondを呼ぶのが手軽です）。

🟩 Q: 重みはどこから調達したの？macOSに入っている？#

重みはAppleが自社で学習した独自モデル「Apple Foundation Model」のもので、サードパーティ製モデルではありません。fmはOS側のモデルを呼び出すフロントエンドにすぎず、コマンド自体は重みを持っていません。

macOSのインストールイメージには含まれていません

fmコマンドは/usr/bin/fmとしてOSに同梱されていますが、重みは別です。macOSアップデートの後、オンデバイスモデルが別途ダウンロードされます。必要なストレージは7GBで、macOS 27インストール後にバックグラウンドで取得されます。つまりApple Intelligenceのアセットとして後から配信される形です。ダウンロードが終わるまではfm availableがmodelNotReadyを返します。

2種類のモデルと重みの所在

Appleのモデルは2つあります。1つは約3Bパラメータのデバイス向けモデル、もう1つはPrivate Cloud Compute内で動くサーバー向けのMixture-of-Expertsモデルです。fm chatで切り替えられる2つのモデルはこれに対応しています。重みがローカルにあるのはオンデバイスモデルだけで、PCCモデルの重みはAppleのサーバー側にあります。

macOS 26世代のオンデバイスモデルは、1重みあたり2ビットまで量子化されていました。macOS 27ではベースモデルが更新されています。アダプタ学習ツールキットの26.0.0は27以降と互換性がないとされており、アダプタは特定のシステムモデルバージョン1つにしか対応しません。そのためmacOS 27のモデルのパラメータ数や量子化方式は、26世代と同じとは限りません。

重みファイルを直接扱えるか

OSのアセット管理下に置かれていて、公開されたファイル形式で自由に取り出したり他のランタイムで読み込んだりする前提にはなっていません。アクセスはFoundation Models framework（とその上のfmやPython SDK）経由に限られます。例外として、Apple Developer Program会員向けのアダプタ学習ツールキットには、アダプタ学習用に最適化されたシステムモデルの重みが含まれています。ただしこれも規約への同意が必要で、学習用途に限られます。

具体的な格納パスは公式には文書化されていません。調べたい場合は、実機でfm availableがreadyになった後、ディスク使用量の増えたシステムアセット領域を探すのが確実です。
