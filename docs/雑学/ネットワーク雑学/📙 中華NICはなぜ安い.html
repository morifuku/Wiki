🟩 中華NICのI350とか、チップまでコピーしたの？Intelのライセンスは？¶

結論から言うと、チップ（シリコン）自体は基本的にコピーではなく本物のIntel I350です。コピーされているのはボード設計とNVMの中身で、怪しい点はそこにあります。

チップについて

I350クラスのコントローラをリバースして互換チップを作るのは割に合わないので、クローンシリコンはまず存在しません。中華カードに載っているのは、次のどれかが多いです。

  • 正規・準正規ルートで流れてきた新品チップ（Intelは基板メーカーにチップを普通に販売しています）

  • 中古サーバーやスクラップ基板から外したリサイクル品（リボール・再マーキングあり）

  • 型番やステッピングを書き換えた再マーキング品

本物のチップを買って載せるだけなら、Intelから特別なライセンスは要りません。

コピーされているもの

  • 基板設計：Intelのリファレンスデザイン（本来はNDA下で配布される回路図・レイアウト）ほぼそのまま、という例が多いです。

  • NVM（EEPROM/Flash）イメージ：Intel純正カード（I350-T2/T4）のイメージを流用し、Subsystem Vendor/Device IDまでIntel純正（8086:xxxx）にしていることがあります。Windowsの純正ドライバやIntel PROSetが純正カードとして認識するのはこのためです。ここが一番グレーで、実質的には「純正のふり」です。

  • ラベル・外箱：Intelロゴ入りの偽リテール品も出回っていて、X520/X540などの偽物の事例が有名です。

実務で困るポイント

  • MACアドレス：OUIがでたらめだったり、複数枚で同じMACが焼かれていたりする事例があります。同一L2セグメントに並べると事故になります。

  • NVMのバージョンが古い・不整合：Intelのnvmupdateツールで更新しようとすると、拒否されたり文鎮化したりすることがあります。

  • リサイクルチップの品質：熱履歴があるので、長期運用での信頼性は読めません。

見分け方（Linux）

lspci -nn -vvv -s <BDF>    # 8086:1521(I350) と Subsystem ID を確認
ethtool -i ethX            # firmware-version(NVM/eTrack) を確認
ethtool -e ethX            # NVMダンプ
ip link                    # MACのOUIをベンダー検索して確認

Subsystem IDが純正カードのIDなのに基板が非Intel、というものは「NVM流用品」と判断できます。

🟩 X550を２万円で買ったけど、サーバメーカーで買うと10万円する¶

2万円と10万円の差は、ほとんどがチップ以外の部分の差です。

10万円の中身

  • サーバーベンダーによる検証済みの組み合わせ保証（BIOS/UEFI、BMC、ファーム更新ツールとの整合）

  • 専用ファームウェア（Subsystem IDがDell/HPE/Lenovoのもの）と、ベンダー経由のNVM更新

  • 保守契約の対象になること

  • 正規ルート・新品チップであることの保証

チップ単価そのものは数千円の世界なので、性能面では中華カードでも同じX550が載っていれば基本的に同等です。

中華X550で注意すべき点

  1. 発熱：X550は10GBASE-TのPHYを内蔵しているため結構熱くなります。安価なカードはヒートシンクが小さかったり、グリスの塗り方が雑だったりします。ワークステーションや静音筐体だとエアフローが足りず、リンクが不安定になったりダウンしたりしがちです。風を当てるのが一番効きます。

  2. NVM/ファーム：ethtool -i でfirmware-versionを確認してください。Intelのnvmupdateは中華カードだと「対象外」で弾かれることが多く、無理に焼くと文鎮化のリスクがあります。動いているなら触らないのが吉です。

  3. MAC重複：複数枚買った場合は必ず確認してください。

  4. リンク速度：X550はNBASE-T（2.5G/5G）にも対応しています。ケーブルや対向機器によっては10Gで張れずに落ちることがあるので、ethtool ethX でネゴ結果を確認しておくと安心です。

lspci -nn | grep -i 1563   # X550-T2 は 8086:1563
ethtool -i enpXs0f0
ethtool enpXs0f0           # Speed / Link detected

中間の選択肢

ヤフオクやeBayにDell/HPEのOEM版X550・X710の中古（サーバー抜き取り品）が1〜2万円台で出ていることがあります。チップの素性はこちらのほうが確かで、ファームもベンダーツールで更新できます。ただしOEM版は、他社サーバーのBIOSで認識しない・警告が出る、といった癖がたまにあります。

検証機や社内ラボ用途なら、2万円の中華X550で十分という判断は合理的だと思います。顧客向けの本番設備に入れるなら、少なくとも数日間の負荷試験（iperf3を長時間＋温度監視）をしてから使うのがおすすめです。
