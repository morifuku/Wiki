🟩 Q: 化学の特許は、とりあえず全組み合わせを「こんなモノができるはず」と網羅的に取得して、あとから「やっぱりそうでした／ダメでした」ってなる？¶

半分は当たっていますが、「とりあえず全部押さえて、あとで答え合わせ」は特許法の要件でかなり制限されています。

広く押さえようとするのは本当です

化学、特に医薬や材料の特許では「マーカッシュクレーム」という書き方がよく使われます。たとえば「R1 は H、C1〜C6 アルキル、ハロゲンから選ばれ、R2 は……」のように置換基の選択肢を並べ、組み合わせで数万〜数億の化合物を一つのクレームに含めます。他社が置換基を少し変えただけで回避するのを防ぐためで、実際に作っていない化合物もたくさん含まれます。

ただし「作れるはず」だけでは通らない

化学は予測が当たりにくい分野なので、審査では次の要件が厳しく見られます。

  • 実施可能要件：明細書を読んだ当業者が、過度な試行錯誤なしにその物を作って使えること。

  • サポート要件：クレームの範囲全体について、実施例などで効果が裏付けられていると言えること。

実施例が数個しかないのに範囲だけ広いと、「その範囲全体で効く根拠がない」として拒絶されたり、登録後に無効にされたりします。日本や欧州では出願後に追加データを出しても、明細書に書かれていない効果を後から補うことはほぼ認められません。

実際の流れ

  1. 合成と評価をある程度進め、代表的な化合物の実施例をそろえて、広めのクレームで早めに出願する（先願主義なので早さが重要）。

  2. 1年以内なら国内優先権やパリ優先権を使い、追加の実施例を入れてまとめ直す。

  3. 審査で拒絶されたら、データで裏付けられた範囲までクレームを絞る。

  4. 本命の化合物（医薬なら開発候補）は、別の出願で個別に固める。

ですので、「あとでダメでした」となる部分は、多くの場合は権利化の途中で削られます。削られずに残っても、無効にされる弱点を抱えたままになります。

後から別の人が取れる余地もある

広い先行特許の範囲に入る化合物でも、そこで具体的に開示されておらず、予想外の優れた効果がある化合物を見つければ、「選択発明」として別に特許を取れることがあります。広く押さえただけでは安心できない理由の一つです。

ちなみに米国では、実験していない予言的な実施例（prophetic example）を書くことが認められています。ただし時制で区別する必要があり（予言的なものは現在形・未来形で書き、実際の結果のように過去形で書かない）、紛らわしく書くと不公正行為を問われる危険があります。
